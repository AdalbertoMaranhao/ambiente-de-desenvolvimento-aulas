🧪 Bem-vindo ao Laboratório Portátil

Seu ambiente de desenvolvimento universal — Windows & Linux — 100% offline

🚀 Como iniciar suas aulas

1

Abra o atalho do seu sistema

No Windows, clique duas vezes em Iniciar <Disciplina>.cmd.
No Linux Mint, clique duas vezes em Iniciar <Disciplina>.desktop.

2

O VS Code abre automaticamente

O editor abrirá com seus arquivos, tarefas e configurações prontas, preservando abas e temas em qualquer computador.

3

Execute os exemplos

Consulte o arquivo README.txt dentro da sua pasta de projetos para instruções de execução da sua disciplina.

💾 Banco de Dados Universal (SQLite)

✓ Zero configuração e sem travamentos de portas: O banco de dados é um arquivo único chamado banco.db localizado dentro da pasta do seu projeto.
✓ 100% Interoperável: Modificações feitas no Windows aparecem de imediato no Linux (e vice-versa), sem necessidade de exportar ou importar backups!

💡 No VS Code, você pode usar a extensão SQLTools (ícone de banco de dados na barra lateral esquerda). A conexão "Banco de Aulas (SQLite)" já vem pré-configurada e pronta para você executar consultas SQL!

📁 Estrutura do seu Pendrive

LocalPara que serve
projetos/Onde ficam seus códigos (.php, .py ou .java) e o arquivo banco.db
configuracoes/Guarda seus temas, histórico de abas abertas e preferências do VS Code
tools/Binários portáteis que fazem o ambiente rodar em Windows e Linux
backups/Onde ficam cópias de segurança geradas pelo comando de backup
