🧪 Bem-vindo ao Laboratório de Programação

Seu ambiente completo para aprender a programar — 100% offline

🚀 Como começar

1

Abra o editor de código

No terminal que abriu junto com esta página, escolha a opção 2 para abrir o editor com o banco de dados ativado.

2

Crie seu primeiro arquivo

No editor, vá até a pasta projetos/php e crie um arquivo chamado meu-primeiro.php.

3

Escreva e execute

Digite <?php echo "Olá!"; ?>, salve e veja o resultado no navegador.

🔑 Conexão com o Banco de Dados (MariaDB)

O banco de dados já está configurado com credenciais padrão para suas aulas:

🌐 Host: 127.0.0.1 | Porta: 3307 | Banco: aulas
👤 Usuário: aluno | Senha: aluno
⚙️ Root (Admin): root | Senha: root

💡 No VS Code, você pode usar a extensão SQLTools (ícone de banco na barra lateral) que já vem com a conexão configurada pronta para conectar!

❓ O que fazer se algo der errado

!

O editor não abre

No Linux, o sistema pode bloquear o VS Code por segurança. Consulte o guia completo LEIA-ME.html para resolver.

!

O banco de dados não liga

Escolha a opção 4 no menu para verificar se todas as ferramentas estão funcionando. Se algo falhar, consulte o professor.

!

Perdi meus dados

Use a opção 5 no menu para fazer backup regularmente. Os backups ficam na pasta backups/.
