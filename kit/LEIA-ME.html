🧪 Laboratório Portátil Universal (Dual-OS)

Ambiente portátil completo de desenvolvimento contendo VS Code, Git, interpretadores/compiladores e banco de dados SQLite. Funciona de forma 100% offline e independente do sistema operacional da máquina (Windows 11 ou Linux Mint x64).

✓ Totalmente Interoperável: Você pode iniciar seus trabalhos no Windows, salvar, plugar o pendrive em um computador com Linux Mint e continuar de onde parou. Seus códigos, banco de dados (banco.db) e abas abertas no VS Code são sincronizados automaticamente!

1. Como Iniciar o Ambiente

Na raiz da pasta do seu kit (ou pendrive), basta acionar o atalho correspondente ao computador que você está usando:

  • No Windows: Clique duas vezes em Iniciar <Disciplina>.cmd. Não requer direitos de administrador.
  • No Linux Mint: Clique duas vezes no atalho Iniciar <Disciplina>.desktop (ou execute via terminal ./iniciar-linux.sh).

O VS Code abrirá automaticamente com seu projeto carregado, extensões ativadas e o banco de dados pronto para uso.

2. Banco de Dados (SQLite)

Para evitar conflitos de portas de rede e falhas de serviços em segundo plano, este laboratório utiliza SQLite:

  • O banco de dados é um arquivo físico chamado banco.db localizado dentro da sua pasta de projetos.
  • No VS Code, basta clicar diretamente no arquivo banco.db para abrir o visualizador interativo (SQLite Viewer), explorar tabelas e rodar scripts SQL.
  • Sem transferências manuais: O arquivo banco.db é binário e idêntico em Windows e Linux.

4. Recursos Pedagógicos Integrados

Todos os perfis incluem extensões visuais selecionadas para apoiar o aprendizado prático e a resolução autônoma de problemas:

  • Error Lens: Mostra a descrição do erro e aviso diretamente ao lado da linha com falha no editor.
  • Indent Rainbow: Facilita a visualização de blocos de chaves, classes e indentação em Python/HTML/PHP/Java através de cores suaves.
  • Better Comments: Destaque para comentários e anotações explicativas no código.
  • Path Intellisense: Sugere e completa caminhos de arquivos em includes, requires e links.
  • Auto Rename Tag: Mantém tags HTML de abertura e fechamento sincronizadas automaticamente.
  • Português (Brasil): Toda a interface do editor está traduzida.

5. Salvando e Transportando seu Trabalho

Basta fechar o VS Code normalmente. Como o SQLite grava as alterações diretamente no arquivo banco.db e o VS Code salva suas preferências em configuracoes/vscode, basta ejetar com segurança o pendrive e você estará pronto para levar seus trabalhos para casa ou outro laboratório.

6. Solução de Dúvidas Comuns

  • O iniciador avisa que o VS Code não foi encontrado: O kit utiliza o Visual Studio Code instalado no computador para garantir leveza e máxima performance, mantendo todas as extensões e preferências isoladas no pendrive. Caso a máquina não possua o VS Code instalado, instale a versão oficial gratuita em code.visualstudio.com.
  • O Linux Mint não deixa executar o arquivo: O iniciador iniciar-linux.sh restaura as permissões de execução dos binários automaticamente. Se o pendrive estiver montado com a opção restritiva noexec, copie a pasta para sua pasta pessoal (ex: ~/aulas) e execute dali.
  • Perdi meu código ou quero voltar uma versão: Use o Git localmente. O terminal integrado do VS Code já tem o comando git configurado sem depender de internet.
