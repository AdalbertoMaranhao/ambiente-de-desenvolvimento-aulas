📁 Projetos PHP

Nesta pasta você cria seus arquivos PHP. Cada arquivo termina com .php

Exemplo simples:
  Crie um arquivo chamado "teste.php" com este conteúdo:
    <?php echo "Olá!"; ?>

Como ver o resultado no navegador:
  1. No menu do laboratório, escolha a opção para abrir o terminal
  2. No Windows, digite: php -S 127.0.0.1:8080
  3. No Linux, digite: frankenphp php-server --listen 127.0.0.1:8080
  4. Abra o navegador e acesse: http://127.0.0.1:8080/teste.php

Dica: o arquivo ola-mundo.php já está pronto para você testar!
