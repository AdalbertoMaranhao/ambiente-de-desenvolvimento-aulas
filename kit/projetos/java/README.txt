📁 Projetos Java (POO)

Nesta pasta você cria suas classes Java (.java).

Como executar:
  Opção 1: No VS Code, abra o arquivo OlaMundo.java e clique em "Run"
           que aparece logo acima de "public static void main".
  Opção 2: No terminal do kit, execute:
    javac OlaMundo.java
    java OlaMundo
