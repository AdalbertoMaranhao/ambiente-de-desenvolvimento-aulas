📁 Projetos PHP com Composer

Nesta pasta você cria projetos PHP que usam o Composer para gerenciar dependências.

O Composer funciona 100% offline neste laboratório. As bibliotecas disponíveis
foram preparadas pelo professor antecipadamente.

Como começar:
  1. Crie um arquivo chamado "composer.json" nesta pasta
  2. No terminal, digite: composer install
  3. As bibliotecas serão instaladas a partir do cache local

Exemplo de composer.json:
  {
    "require": {
      "monolog/monolog": "^3.0"
    }
  }

Importante: apenas as bibliotecas que o professor incluiu no pacote
estão disponíveis. Se precisar de outra, peça ao professor.
