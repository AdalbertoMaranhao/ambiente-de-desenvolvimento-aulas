📁 Projetos Java (POO)

Nesta pasta você desenvolve seus programas Java (.java).
Coloque seus arquivos de código-fonte dentro da pasta "src/".

Exemplo incluído:
  • src/OlaMundo.java - Primeiro programa em Java (Olá, mundo!)

Como executar:
  • No Windows (IntelliJ IDEA):
    Abra pelo menu do kit ("Iniciar Java.cmd").
    O IntelliJ abre com o JDK portátil (JDK-Kit) pré-configurado.
    Clique no botão Run (▶) no canto superior direito para rodar a classe OlaMundo.

  • No Linux (VS Code):
    Abra pelo menu do kit ("iniciar-linux.sh").
    Abra o arquivo src/OlaMundo.java e clique no botão "Run" acima de main.

  • No terminal do kit (Windows ou Linux):
    javac -d out src/OlaMundo.java
    java -cp out OlaMundo
